# BELLO → Next Engine → メルカリShops

## 本人の最新テスト指示（2026-09-28）

ネクストエンジン経由のAPI出品を完成まで継続する。メルカリShopsへのテスト登録は非公開のみ許可。公開への切替は許可されていない。既存販売中の商品を変更して試さない。

公式連携マニュアル21ページでは商品ステータスを「ページ情報 > 公開・非公開」から引き継ぎ、0=非公開、1=公開。テスト実行前は正規APIで取得したページ値が0であることを検証する。未設定・不明・1では停止。`privateTestPolicy.ts`はこの判定だけを実装し、商品マスタ登録を非公開出品完了とは扱わない。

正規公開APIから連携アプリの新規出品起動経路は引き続き未確認。内部通信で代用しない。

## 確認した経路

- ログイン済み管理画面で自社専用アプリの登録フォームを準備。アプリ名は「BELLO EC出品連携」、販売形態は特定企業向け。保存・認証情報発行はまだ行っていない。
- メルカリShops連携アプリは新規出品に対応するが、メルカリShops側アクセストークンは別途必要。登録料・月額は0円表示。利用開始には利用規約と企業/ユーザー情報共有への同意が必要。
- 自社向けAPI利用は月1000回/3GB以内が無料、1001〜2000回/4GB以内は税抜月5000円という管理画面表示を確認。契約前に最終条件確認。自動ポーリングを常時行う設計は避ける。

## 公開APIの境界

商品マスタのアップロードは公式POST `/api_v1_master_goods/upload`。非同期受付のque_idを取得後、アップロードキューで結果確認する。受付successを出品完了と扱わない。

商品ページ・商品画像の公開APIは検索/件数取得であり、ページ作成やモールへのアップロードAPIは提供されていない。第三者のメルカリShops連携アプリの新規出品を呼び出す公開APIも確認できていない。内部通信やログイン情報を抽出して代用しない。

初期実装は商品マスタCSV準備のみ。仕入先コードを明示入力し、在庫・公開タグ・実出品を変更しない。ページ/画像登録と新規出品操作の経路を確定するまでワンクリックAPI出品完了とは表示しない。
