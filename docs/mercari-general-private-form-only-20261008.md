# B005396 汎用非公開下書きフォーム入力の実装境界（2026-10-08）

`tools/bello-mercari-bridge/src/generalPrivateCreateFormOnly.mjs` は、レビュー済みのBELLO手動出品パックを専用ブラウザーのメルカリShops新規商品フォームへ一度だけ入力するための内部関数である。現時点で画面ボタン、CLI、キュー送信口には接続していない。実店舗での実行、画像アップロード、Shopsへの保存・作成・公開は行っていない。

## 順序と停止条件

1. ローカルの不変パックを読み、対象在庫・店舗・価格・数量・商品管理コード・状態・カテゴリ・配送4項目・画像参照の厳密な形を確認する。ブランド指定があるパックは、画面操作が未確認のため停止する。
2. 出品中と下書き一覧の読取が完全で、対象SKU・同名の候補がないと判定された場合だけ進む。`NO_MATCH_IN_OBSERVED_UI` も作成許可ではなく、この関数のフォーム準備条件に限る。現在のB005396観測は `REMOTE_SCAN_INCOMPLETE` なのでここで停止する。
3. BELLO管理者の専用ブラウザーで保存済み下書きを再照合し、同じ画像参照から画像バイトを取得する。保存値や画像が変わった場合はShopsを開かない。
4. Shopsブラウザーを開く**前**に永続的な一回限りの `UNKNOWN` claim を残す。新規画面は操作だけで下書きが自動保存された観測がある。ログイン失効、画面変更、部分入力、ファイル選択の失敗は再試行しない。
5. 専用プロファイルの復元ページを拒否し、固定店舗の一覧URLから観測済み「商品登録」リンクを1件だけ選ぶ。リンク先と新規画面URLを固定店舗に照合する。商品名・説明・価格・数量・商品管理コード・配送・状態・カテゴリ葉・画像を入力し、画面表示を再読取する。
6. 結果は `FORM_READY_NO_SAVE` または `UNKNOWN`、`listingConfirmed=false`、`allowSave=false` として記録する。`productDraftId` が現れても商品IDや非公開出品成功とは扱わない。「公開設定に進む」「下書きへ保存する」「公開する」「非公開で保存する」は呼ばない。

## 残る観測と受入

- B005396の実際のBELLO画像バイト、Shopsの画像アップロード後の同一バイト保存、カテゴリ葉・ブランド・配送設定の実画面一致はまだ確認していない。内部関数に画像参照と画面値の照合を用意したが、実運用の証拠にはしていない。
- B005396のリモート一覧は走査未完了。別下書きとの重複を否定できないため、現在のデータではフォーム入力にも進まない。
- 保存・非公開作成へ進むには、作成要求と応答の対応、別画面での商品ID・非公開状態・画像の再読取が必要。保存ボタンを実装する際は `withShopListingSend` の店舗共通30秒以上の間隔制御と、待機後のフォーム再照合を必須にする。今回の内部関数にその操作はない。
- AWSの `Bello` プロファイルは同じ検証アカウントへの再認証を確認したが、BELLO管理者ログインやメルカリShops専用ブラウザーログインを意味しない。

## 10月8日のB005396画面確認と下書き保存の境界

BELLOの管理画面には、EC下書き価格50,000円、Shops確認用価格99,999円、数量1、状態「目立った傷や汚れなし」、家具・インテリア > ソファ・ソファベッド > 2人掛け・3人掛けソファ、写真参照1件が表示された。EC配送は家財便で、説明文には家財便Eまたは自社配送と地域ごとの配送相談に関する記述がある。Shopsの新規商品画面では「未定（出品者が手配）」「送料込み（出品者負担）」「埼玉県」「4〜7日で発送」が表示された。これらは画面表示の観測であり、画像バイト、アップロード結果、保存結果の証明ではない。

本人指定のShops配送4項目は固定設定として照合する。「未定（出品者手配）」はBELLOの家財便Eと同一サービスという意味ではない。現行の説明は地域ごとの配送相談であり、追加料金を確定して告げる文面とは判断しない。非公開下書き保存の一回限りの記録には `shippingReviewRequired=true` を商品パックの指紋とともに残し、公開前に配送条件と対象地域の案内を改めて確認する。BELLOの保存済み下書きと選択価格・数量は保存前にも再読取する。

`generalPrivateDraftSaveOnce.mjs` は未接続の下書き保存経路である。BELLOの管理者読取はB005396の元のEC価格50,000円、配送方法 `KAZAI`、保存済みパック、画像バイトを再取得し、入力時のSHA-256と保存直前のSHA-256を一致させる。専用店舗・商品コード・自分の下書きIDに結び付いた重複なしの読取証拠は、現在まだ生成できないため既定では停止する。条件が揃った試行だけ、永続的な一回限りの記録と店舗共通30秒ゲートを通し、観測済みの「下書きへ保存する」ボタンだけを対象にする。押下後は `UNKNOWN` とし、別の認証済み読取で全項目と画像の画面上の同一資産を確認できた場合にのみ非公開下書きと記録する。公開や商品出品成功には昇格しない。
