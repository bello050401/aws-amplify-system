# BELLOからメルカリShopsへの一操作出品: 実装境界

確認日: 2026-10-02。外部の公開・販売を伴う操作は本調査で実行していない。

## 実証済み

- BELLOからNext Engineの商品マスタへ専用商品を一度送信し、アップロードキュー成功とSKU完全一致のマスタ読戻しを確認した。記録は `outputs/private-master-second-attempt-acceptance-20261002.md`（作業タスク側）。
- 検証環境の送信ゲートはすべてOFFに復帰した。旧・第2試行の送信マーカーは保持している。

## 公式資料で確認した境界

- Next Engineの公開APIには商品マスタのアップロードがある。一方、商品ページ作成とモールへのアップロードを行うAPIは提供しないと公式FAQに記載されている。商品ページAPIの公開一覧も検索・件数取得のみ。[Next Engine FAQ](https://developer.next-engine.com/faq/08-goods/) / [商品ページAPI](https://developer.next-engine.com/api/api_v1_master_goods_page/)
- メルカリShops連携アプリは新規出品に対応するが、マニュアルの新規出品はアプリ画面の「商品を出品する」ボタンで開始する。自動更新は既存商品向けで、新規商品を追加出品しない。[連携アプリマニュアル](https://mrs.ne-receiver.com/manual)
- 連携アプリの新規出品には画像、ページ掲載商品名・説明、カテゴリ、商品状態、価格、ページ公開状態等が必要。商品分類タグ `[メルカリShops出品]` と画像分類タグの設定も指定されている。[連携アプリマニュアル](https://mrs.ne-receiver.com/manual)
- 商品分類タグは商品マスタCSVの `tag` 列で登録でき、商品マスタアップロードAPIのCSV例にも同列がある。既存タグのある商品は全タグを含めないと上書きされる。画像はCSVの `image_url_http` に外部公開URLを指定して取り込めるが、画像ファイルそのもののアップロードAPIや画像分類タグの書き込みAPIは確認できない。[Next Engine公式ブログ](https://next-engine.net/more-ne/20171214/) / [商品マスタアップロードAPI](https://developer.next-engine.com/api/api_v1_master_goods/upload/) / [画像登録Q&A](https://developer.next-engine.com/questions/1068/)

## 実装経路

経路は **BELLO → Next Engine → メルカリShops連携アプリ → メルカリShops** に限定する。BELLOからメルカリShopsへ直接送信する処理は追加しない。

BELLOの一操作で商品マスタと商品分類タグを登録する経路はある。ただし、商品ページ・画像分類タグ・連携アプリの「商品を出品する」は確認済みの公開APIから完結しない。公式に自動起動できる手段を確認するまでは「メルカリShopsへの一操作出品」を完成扱いにしない。

実装は、保存済みの在庫と下書きから送信内容を確定し、商品マスタのアップロード結果と読戻しを確認する段階まで進める。連携アプリの提供元には、(1) 新規出品を外部から起動する正式なAPI・Webhook等の有無、(2) 商品ページと画像分類タグを外部から登録する正式手段、(3) 実行結果をSKU単位で取得する手段を確認する。外部への登録や公開は、対象・内容・重複防止・結果確認を確定してから行う。

BELLOからネクストエンジンの商品マスタアップロードAPIでSKUを登録し、メルカリShops連携アプリを通じて新規出品する構成を検討しています。商品マスタの登録と読戻しは検証済みです。以下について、提供されている正式な連携方法と仕様書をご教示ください。
