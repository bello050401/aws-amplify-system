`UNVERIFIED` が42件あるのは、外部API（Mercari / BASE / ZAICO）の応答仕様を
ドキュメントではなく実物で確かめないと確定できないものが多いため。推測で
埋めずに「未確認」と書いてあること自体は正しい状態で、実機確認（A・C）が
進むと減る。

## いま止まっている一番の理由

**C の1件目（Staging資格情報の登録）。** これが入ると A の6件が一斉に動き、
その結果が B の判断材料になる。逆にここが空いている間は、A も B も進まない。

D はその間も進められるので、承認待ちの間は D を進める。
