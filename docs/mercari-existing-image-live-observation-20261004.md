# B005795 既存画像1枚選択の実機観測（2026-10-04）

## 実行範囲と結果

- 本人が旧専用Chromeを閉じた後、旧PCアプリの終了可能化と正常終了を確認し、画像機能を追加した設置版を起動した。
- 対象は既存の非公開商品B005795だけ。PCアプリの「既存商品に画像を1枚追加して観測」を1回実行した。結果は `UNKNOWN / FILE_SELECT_RETURNED`。ファイル入力への選択呼出しは戻ったが、アップロード完了や商品への関連付けを保証しない。永久試行マーカーがあり、再実行ボタンは無効。
- 専用Chromeと通信観測は現在も開いている。アプリの終了ボタンも無効。画像の再選択、商品保存、公開、新規商品作成、マーカー解除、Chrome終了は行っていない。

## PCアプリに表示された秘密値を含まない通信概要

これは現在のループバックPC画面の表示を読み取ったもの。要求・応答本文、画像データ、認証値、可変URL、GraphQL変数値を保存していない。全件で認証ヘッダーとCSRFヘッダーの存在フラグは「なし」。

## 現在セッションの読取境界

稼働中PCアプリは同じPlaywright `page`を保持しているが、公開するローカル操作は通信概要更新だけ。画像一覧を再読取する操作はない。保存後のコード差し替えも稼働中のNodeプロセスには反映されない。ブラウザー操作ツールに当該Chromeのタブは表示されず、Windows Computer Useは対象URLを安全に特定できず読取前に停止した。同じプロフィールを別プロセスで開かず、現在のセッションを閉じず、画像選択を繰り返さない。

作業ブランチの次版コードには、保持中の同じ `page` に限り、対象の正確な編集URLと商品管理コード等を再照合して、既存の `readExistingUploadedImages` で画像の枚数・元画像のパスハッシュを読む専用ボタンを追加した。表示は固定の結果コードだけで、URLや画像自体は表示・保存しない。合成テストは通過したが、設置済みの稼働プロセスには反映していない。導入には再起動が必要で、**現在の未保存画面を保持したまま今回のセッションへ後付けできない**。今回の画面を確認するには、本人が現在開いている専用Chromeをそのまま見て、元画像と追加画像の表示を伝えるか、秘密値のない画面写真を提供する必要がある。
