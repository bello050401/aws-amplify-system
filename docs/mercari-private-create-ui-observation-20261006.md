画面上部には「公開設定に進む」「下書きへ保存する」が別々にあり、「この商品は下書きです」と表示された。今回はどちらも押していない。既存商品画面で見た「非公開で保存する」モーダルを新規画面へ外挿しない。

**自動保存の予期しない観測（UNKNOWN / unattributed）:** 最初の新規画面はURLに `productDraftId` がなく、商品名・価格は空、数量は1だった。カテゴリ欄を開き、「家具・インテリア」→「机・テーブル」の親階層を押して選択肢を読んだ。葉カテゴリ、商品情報、画像は選択・入力せず、Escapeでモーダルを閉じた直後、URLが `/products/create?productDraftId=2JXmhh6wZFnKBnhwk8zV9c` となり、「下書きに保存しました」のトーストが出た。正確にどの操作で下書きが作られたか、商品レコードが存在するかは未確認。下書きIDは新規商品の確定IDとして使わない。この時点でShops画面操作を停止し、削除も再操作もしていない。現行の `PREPARED_NO_SEND` 入力は `productDraftId` を受け付けず、生成記録の `remoteId` は `null` のまま。将来の作成実行器は**新規画面を開く前**に一回限りのclaimを残し、既存のリモート下書きがないと仮定せず、ログイン・画面遷移・自動保存後の不明状態を自動再試行しない必要がある。

非公開作成を完了扱いにするには、本人指定の未出品在庫IDと価格、BELLO保存済み下書き、店舗・商品管理コード・画像・カテゴリ・配送の完全一致を事前確認したうえで、同じ試行に属するShopsの新規作成要求と応答から**商品IDと非公開状態**を取得し、別の認証済み商品画面で再読込して照合する必要がある。`productDraftId`、HTTP 200単独、画像アップロード応答単独、一覧行単独を商品作成成功とみなさない。これらの実要求・応答はまだ観測していない。
