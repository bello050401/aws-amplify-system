## PC観測機能の差分

現行のPC照合アプリは、専用Shops Chromeで通常の商品読取中に発生する `fetch` / `xhr` のmethod、固定語彙に丸めた送信先、HTTP状態、件数のみをメモリ内に表示する。処理順、送信項目名・型、応答ID・状態は取らない。読取後にChromeを閉じるため、人が行う保存操作を観測する機能もない。

新しい `manualMutationObservation.mjs` は、既存商品の正確な編集URLにいる1ページへ**受動的に取り付ける部品**として準備した。自ら通信・クリック・保存をしない。POST/PUT/PATCH の `fetch` / `xhr` について、順番、method、固定語彙に丸めた送信先、既知の商品項目名と値の型、認証ヘッダーの有無、HTTP状態、認識できる応答の商品・画像IDと公開状態だけをメモリ上に返す。JSONまたはmultipartの値、ファイル名、画像データ、クエリ文字列、Cookie・Bearer・CSRFの値、丸ごとの本文、未認識項目名、エラー本文は返さない。外部HTTPSの送信先は `external-https` と表示する。終了時は新規要求の受付を止め、受理済み要求の応答を最大2秒だけ待ち、時間切れなら未確認のまま返す。合成試験で秘密値の非出力、イベント順序、遅延応答、未完了本文を確認した。

PC画面には、非秘密のローカル設定 `manualObservation` で対象のshop ID・既存product ID・SKU・確認用価格・数量を固定した場合だけ、既存商品の非公開保存を1回押すボタンを表示する。専用Shops Chromeプロファイルで正確な編集URL・商品コード・価格・数量・商品名を読み、非公開一覧の該当行から同じ商品IDへ戻れることを確認する。保存前に永続一回マーカーを記録し、観測済みの「公開設定に進む」から「非公開で保存する」だけを押す。商品項目は編集しない。通信の契約は未確認なので保存成功を断定せず結果は `UNKNOWN` と記録する。保存後は通信を中断しないようChromeを開いたままにし、PC画面でメタデータを更新できる。人がShops画面で処理完了を確認してChromeを閉じると観測を終了する。BELLOへの保存結果送信、新規出品、公開、再送は行わない。

この新しい画面入口の合成試験は通過したが、実通信観測はまだ行っていない。内部HTTPの送信契約、画像アップロードの順序、応答IDの形は未確認であり、自動出品可能とは判定しない。保存結果不明時はマーカーを残して再送しない。追加の確認は既存IDの読取だけで行う。
