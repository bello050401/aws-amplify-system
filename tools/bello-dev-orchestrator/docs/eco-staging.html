staging検証: 問い合わせ 来店・家具選び相談・取り置き（task_d4d9d4bce21fbd475c）

npm run verify:inquiry-visit-consultation / npm run verify:inquiry / npm run verify:line-notify を実行して確認する。

  • 商品未特定でも来店案内（大型家具1点への絞り込み、準備約1週間、平日9-17時）を返す。
  • 家具・照明選びの相談は担当者引き継ぎとし、判定時刻・根拠・理由・現在の状態・次のアクションを社内通知に含める。
  • 相談を検出したメッセージが履歴のwindowから外れても、ConversationContext.reviewReasonsへの符号化により引き継ぎ状態を失わない。
  • 取り置き・配送目安は通常購入後約2週間、1か月超の長期取り置きは個別確認とする。

対象アプリ別承認プロファイル（task_3b0d70a35afb15e898）

eco runtime設定は常に対象アプリを1つだけ明示し、未設定または不一致は開始時点で失敗する。

  • Photo Station（WPF/Node）はローカルbuild・test・UI証拠のみで判定し、ブラウザQAとstaging反映は行わない。
  • 在庫管理Web、EC、ZAICOはそれぞれ自身の実staging識別子でのみ確認し、static smokeの成功を証拠として扱わない。
  • 対象不一致・profile未接続は待機または明確な失敗とし、QAからstagingへ進めない。
  • npm run test tools/bello-dev-orchestrator/test/eco-service-runtime.test.mjs を実行して確認する。
