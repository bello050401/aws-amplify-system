# ZAICO API 画像取得検証(読み取り専用・単一在庫のみ)

BELLO在庫管理システムへのデータ移行に向けた事前検証です。
**本番の移行処理は実装していません。** ZAICO APIから在庫ID1件の情報(画像を含む)を
取得できるかを確認するだけのスクリプトです。

## 実行環境について(重要)

このスクリプトは **Windowsローカルの Claude Code CLI / ターミナルで実行してください**。
このリポジトリを開いているリモート実行環境(claude.ai/code)は、ネットワークポリシーにより
`zaico.co.jp` 系ドメインへ到達できないため、このスクリプトをリモート側で実行しても
必ず失敗します(疎通確認済み)。

## 事前準備

1. このブランチ(`claude/image-fetch-api-5r217s`)をローカルにpull/checkoutする
2. Node.js 18以上がインストールされていること(`node --version`で確認)
3. ZAICO APIトークンを用意する(zaico管理画面の「ユーザー管理」→「ユーザー情報」で
   API機能を有効化し取得したトークン)

## トークンの設定(いずれか)

スクリプトは以下の優先順位でトークンを探します。**トークンの値をClaude Codeの
チャットに貼り付ける必要はありません。**

1. 環境変数 `ZAICO_API_TOKEN` (既に設定済みであればそれを自動的に使用します)
2. リポジトリ直下の `.env.local` 内の `ZAICO_API_TOKEN=...` 行
   (`.env.local` は `.gitignore` 済みで、Gitにはコミットされません)

まだ設定していない場合、PowerShellで以下のいずれかを実行してください
(`ここにご自身のZAICOトークンを貼り付け` の部分だけご自身の手元で書き換えてください):

```powershell
# このターミナルセッションのみ(一時的)
$env:ZAICO_API_TOKEN = "ここにご自身のZAICOトークンを貼り付け"
```

```powershell
# Windowsユーザー環境変数として永続化(要ターミナル再起動)
[System.Environment]::SetEnvironmentVariable("ZAICO_API_TOKEN", "ここにご自身のZAICOトークンを貼り付け", "User")
```

```powershell
# .env.local に追記する場合(リポジトリ直下で実行)
"ZAICO_API_TOKEN=ここにご自身のZAICOトークンを貼り付け" | Out-File -FilePath .env.local -Encoding utf8 -Append
```

トークンを未設定のまま実行すると、スクリプトが同じ案内を表示して停止します
(トークン値そのものはログに一切出力されません)。

## 実行方法

```powershell
node zaico-verification/verify-inventory.mjs 73638418
```

第1引数を省略すると `73638418` が使われます。

## スクリプトが行うこと(読み取り専用)

- ZAICO API v1 (`GET /api/v1/inventories/{id}`, Bearer認証) を呼び出す
- ZAICO API v2 の候補エンドポイントも参考として試行する
  (**注記: このリモート環境からは公式v2ドキュメントページを直接取得できず、
  v2の正式なエンドポイント/認証仕様を未確認です。ローカル実行時にインターネットへ
  アクセスできる状態で、実際のレスポンスと公式ドキュメント
  https://zaicodev.github.io/zaico_api_doc/ を突き合わせて確認してください**)
- レスポンス内から画像/添付ファイルらしいフィールド(`image`, `item_image`, `photo`,
  `attachment`, `file` 等を含むキー、および画像拡張子を含むURL文字列)を再帰的に探索
- 見つかった画像URLの1件目について、認証ヘッダーなしでダウンロードを試行し、
  成功可否・Content-Type・サイズを記録
- 結果一式を `zaico-verification/output/inventory-<ID>.json` に保存
  (`.gitignore`対象、Gitには含まれません)
- 何も書き込み・更新・削除は行いません(GETのみ)
